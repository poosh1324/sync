Run claude in 3 terminals on the same repo. Sync silently makes them aware of each other, prevents file-write collisions, and shares newly-created exports. Zero workflow change.

$ git clone https://github.com/poosh1324/sync && cd sync
$ bun install
$ bun run src/cli/index.ts init   # in your project
$ claude     # terminal 1 — just like always
$ claude     # terminal 2 — sync handles the rest

Three pillars

No debate. No voting. No coordinator. Just three things, in every session, automatically.

01 — AWARENESS

Every session sees every other session

What they're working on, what files they're touching, what symbols they're about to export. Injected into Claude's context on every prompt.

02 — CONFLICT AVOIDANCE

Two sessions never write the same file

File-level locks via the PreToolUse hook. The second session is told politely to pivot — and it does, because Claude reads the reason.

03 — RESULT SHARING

New exports propagate before the next turn

When session A ships createComment(), sessions B and C learn about it on their very next prompt — and use it instead of duplicating.

How it works

Pure Claude Code hooks (4 of them) + a tiny local Bun daemon. No SaaS, no API key, no MCP server, no agent framework.

┌──────────┐ ┌──────────┐ ┌──────────┐ │ claude 1 │ │ claude 2 │ │ claude 3 │ └────┬─────┘ └────┬─────┘ └────┬─────┘ │ hooks │ hooks │ hooks │ (4 lifecycle events) │ └──────────────┴──────────────┘ │ ┌───────▼───────┐ │ sync daemon │ Bun.serve + bun:sqlite │ 127.0.0.1:7777│ state · locks · intents · exports └───────┬───────┘ │ /state every 500ms ┌───────▼───────┐ │ sync mon │ Ink TUI dashboard └───────────────┘

Why this and not…

Three other tools live in this space. None of them solve the same problem.

claude-presence (MCP)

Manual /register + /claim commands. Advisory only — Claude can ignore it. Sync is automatic and enforced via PreToolUse deny.

Claude Code Agent Teams

Top-down lead-coordinator. Requires you to write the task list and assign roles. Sync is peer-to-peer with no spec at all.

Sync — the way you already work

You open N terminals. You type tasks. Sync makes them coherent. No spec, no commands, no overhead. Same working tree, symbol-level awareness.
